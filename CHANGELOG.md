# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/) (SW-10).
Версия прошивки задаётся в `core/include/core/version.h`.

## [Unreleased] — уточнения ТЗ 5.7 (решения по DEV-12)

### Изменено

- MAP-15b: в воздухе (TAKEOFF / IN_AIR / LANDING) без валидной высоты дальномера дольше 500 мс земля не распознаётся (все цели
  реальные), IN_AIR → FLIGHT; `TOF_HEIGHT_GROUND_M` в воздухе не используется. Высота невалидна, только если валидного отсчёта
  не было 500 мс (одиночный отсчёт вне диапазона её не сбрасывает).
- MAP-14b: `CAL_TOL_DEG` — допуск только по азимуту; новый параметр `CAL_TOL_EL_DEG` (0,5°) по углу места; формат слота
  параметров 3, `docs/params.md` перегенерирован.
- MAP-16a: гистерезиса по высоте нет; FLIGHT покидается только при LS = LANDING / ON_GROUND или PHASE_UNKNOWN (LS = TAKEOFF и
  disarm в воздухе его не меняют); после PHASE_UNKNOWN FLIGHT — только по правилу входа.
- FLT-03a: команда удержания — первая передача и до 5 повторов (всего 6), «TOF HOLD REJECTED» — через 500 мс после шестой.
- ТЗ: добавлен подраздел 5.7; DEV-12 закрыт частично.

## [Unreleased] — E1 «Ядро», часть b

### Добавлено

- `ground` (MAP-14, MAP-14a, MAP-15, MAP-18, MAP-19): точный минимум высоты точки по угловой протяжённости зоны + CAL_TOL_DEG
  (не по центральному лучу), классификация каждой цели отдельно, источник высоты корпуса по фазе; статус модели — «не подтверждена
  до T-25/T-26».
- `fusion`: два вида карты — все цели (KEEP) и только реальные препятствия (земля → 65535), у каждого свой автомат MAP-13;
  реальное препятствие за землёй в том же секторе передаётся; число зон GROUND_SUSPECT на кадр; сброс ячеек.
- `phase` (MAP-16, MAP-17, MAP-07, MAP-07a): автомат фаз по armed, landed_state и высоте (подтверждение 1 с с гистерезисом,
  GROUND_RECOVER, PHASE_UNKNOWN), политика экспорта и разрешение команды удержания по таблице 5.4; DROP — только в FLIGHT,
  только при флаге сборки `TOF_ALLOW_GROUND_DROP` и валидной высоте.
- `mavlink_tx` / `mavlink_rx` (ICD-01, ICD-03, ICD-04): кодеры исходящих сообщений раздела 6 (из команд — только
  SET_MESSAGE_INTERVAL и DO_SET_MODE в BRAKE/LOITER), парсер со своими буферами, кольцевой буфер ATTITUDE с интерполяцией
  на момент кадра, дальномер orientation 25, таймауты, ответы UNSUPPORTED на команды компоненту 196; fuzz-тесты.
- `fault_fsm` (FLT-03…FLT-06, FLT-08, FLT-10): команда удержания на шаге обнаружения, 5 передач через 500 мс, успех только по
  режиму в HEARTBEAT, один успешный перевод на эпизод, возврат AUTO пилотом — только предупреждение, «TOF HOLD REJECTED»,
  рестарт в полёте, «виртуальная стена» (FAULT_WALL = 0 по умолчанию).
- `events` (DIA-03, DIA-04): STATUSTEXT по смене состояния с гистерезисом, дедупликацией и лимитами 1/с на тип и 3/с всего;
  в наземных фазах — только реальные препятствия; «TOF ORIENT NOT CONFIRMED» (SNS-12a), «TOF PARAMS DEFAULT» (SW-07),
  «TOF READY» с версией; журнал событий (истечение удержания MAP-13, COMMAND_ACK, фазы, отказы).
- `scheduler` (MAP-12, ICD-02, FLT-01, FLT-02): конвейер кадр → карта → OBSTACLE_DISTANCE за один проход суперцикла,
  запись карты для лога с отметками t1…t5, классы отказов FLT-01, остановка передачи при LOST и HEARTBEAT CRITICAL,
  SET_MESSAGE_INTERVAL при старте и раз в 5 с, NAMED_VALUE_INT по параметру, очередь TX без блокировки.
- Host-тесты: `test_ground`, `test_phase`, `test_phase_drop`, `test_mavlink`, `test_fault_fsm`, `test_events`,
  `test_scheduler` (имитатор FC и трёх датчиков).

### Изменено

- `fusion_push_frame` и `tof_core_push_frame` принимают контекст земли кадра (`ground_ctx_t`, `NULL` — без классификации).
- `core/` линкуется с заголовками `third_party/mavlink/c_library_v2` (без изменений).

## [Unreleased] — E1 «Ядро», часть a

### Добавлено

- `params` + `crc32` (SW-07): единая таблица параметров раздела 15 (имя, тип, умолчание, min, max), проверка диапазонов и
  межпараметрических ограничений, слоты A/B с заголовком (magic, версия формата, длина, порядковый номер, CRC схемы, CRC-32),
  запись в неактивный слот с проверкой чтением, только при disarmed; оба слота невалидны → безопасные умолчания и событие.
- `geometry` (MAP-01, MAP-02, MAP-04): углы зон по 5.1, монтаж Rz·Ry·Rx + t_m, выравнивание по ATTITUDE, d и ψ в корпусной СК,
  угловая протяжённость зоны, высота точки h_p, ORIENT_TRANSFORM (поворот/зеркало) с обратным преобразованием.
- `frame.h` (SNS-06, SNS-09): кадр датчика с метаданными и шестью выходами ULD; `quality` (MAP-03): валидность цели, до 2 целей на зону.
- `cell_fsm` (MAP-13): автомат удержания и снятия препятствия по таблице 5.3.
- `sensor_health` (SNS-11, MAP-10): решение о переинициализации одного датчика, FAILED с повтором раз в 10 с, OK/DEGRADED/FAILED.
- `fusion` (MAP-05, MAP-09, MAP-11): сетка 72 × 5° по протяжённости зон + CAL_TOL_DEG, правила перекрытия, окно слияния,
  время ячейки по самому старому вкладу, STALE, состояние карты, экспорт по 5.2.
- `tof_core`: API ядра — кадр датчика и `now_us` на входе, здоровье и карта на выходе.
- Host-тесты: `test_params` (мок NOR-flash с обрывом питания на каждом байте), `test_geometry` (весь список критерия MAP-02),
  `test_quality`, `test_cell_fsm` (каждый переход 5.3), `test_sensor_health`, `test_fusion`, `test_tof_core`.
- `docs/deviations.md`: DEV-02…DEV-10 — толкования неоднозначностей ТЗ, ожидают решения человека.

### Исправлено по независимой проверке

- Кадр с меткой времени чуть позже `now_us` больше не отбрасывается как опоздавший (MAP-09).
- Слияние не ждёт датчик в переинициализации (MAP-12).
- Кандидат CLR — по 5.3 независимо от включения CLEAR_MEASURED; при выключенном снятие идёт в UNKNOWN через 3 кадра (DEV-02).
- Отсчёт удержания не идёт назад от более старого кадра (MAP-13); протяжённость зон хранится в `fusion_t` (MAP-02).
- Сохранение параметров пересканирует слоты (T-27 при сбое чтения на старте); проверка ROW_MASK; REQ-теги; тесты MAP-02 дополнены.

### Уточнения ТЗ 5.6 (решения человека по DEV-02…DEV-11)

- ТЗ: добавлен подраздел 5.6 (MAP-13a, MAP-09a, MAP-05a, MAP-10a, MAP-14a, MAP-07a, SNS-12a, SW-07a); DEV-02…DEV-11 закрыты.
- MAP-13a: кандидат CLR при выключенном CLEAR_MEASURED — только от валидной цели дальше max_distance; пустая зона — INV.
- MAP-09a: режим STAGGERED — слияние на каждом кадре (`fusion_run_staggered`), отметка t1.
- MAP-05a: параллакс — протяжённость каждой цели на её дальности с учётом MOUNT_XYZ_M.
- MAP-10a: доля валидных зон по зонам с целью; параметр `AMBIENT_DEGRADED` (медиана ambient, по умолчанию выключен).
- MAP-14a: высоты от центра корпуса; расчёт h_body от датчика и от дальномера.
- MAP-07a: флаг сборки `TOF_ALLOW_GROUND_DROP` (по умолчанию 0) блокирует DROP.
- SNS-12a: параметр `ORIENT_CONFIRMED` (по умолчанию 0) — карта не выше DEGRADED; флаг события для STATUSTEXT (E1b).
- SW-07a: `docs/params.md` генерируется из таблицы (`tools/params_md`), актуальность проверяется в CTest.
- Формат слота параметров — версия 2 (слоты версии 1 не загружаются → безопасные умолчания).
- `.gitattributes`: `* text=auto eol=lf`.
